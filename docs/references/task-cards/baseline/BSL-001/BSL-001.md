# BSL-001 — Monthly DNS query volume baseline

## Why
Egress DNS is a common channel for beaconing and data exfiltration. This task
re-establishes what "normal" outbound DNS looks like each month so that the
`BSL-001` baseline stays current and deviations (new resolvers, unusual record
types, sustained high-entropy names) are judged against recent data rather
than a stale snapshot.
