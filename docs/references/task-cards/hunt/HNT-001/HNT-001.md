# HNT-001 - Monthly encoded PowerShell persistence hunt

## Why
Encoded PowerShell launched from common persistence locations can conceal
malicious execution among legitimate administration. This recurring hunt tests
for encoded or obfuscated PowerShell associated with scheduled tasks, services,
and startup entries, then records accepted administrative patterns so each run
can focus on new or changed behavior.
